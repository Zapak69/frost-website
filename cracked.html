Install Guide

Installing Frost on a cracked account

The official Minecraft launcher and the official Modrinth App both require a premium (Microsoft-authenticated) Minecraft account — neither supports cracked/offline accounts. If that's what you play on, this guide walks you through installing Frost with AstralRinth instead — a fork of the Modrinth App with offline account support. It takes about five minutes.

Step-by-step installation

1

Download AstralRinth

Open the AstralRinth releases page and grab the newest release for your system:

  • Windows — the .msi (or .exe) installer
  • macOS — the .dmg file
  • Linux — the .AppImage, .deb or .rpm, whatever fits your distro
2

Install and launch it

Run the downloaded installer and go through it like any other app, then launch AstralRinth. It looks and works almost exactly like the official Modrinth App — same layout, same flow — so anything written about the Modrinth App applies here too.

3

Add your offline account

Click the account icon in the top-right corner of AstralRinth, choose the offline account option, and type the username you want to play under. That's the whole sign-in — no Microsoft login needed.

4

Download Frost

Click the download button on the Frost homepage, pick your renderer (Vulkan or OpenGL) and Minecraft version, and you'll be redirected to Modrinth — download the .mrpack file from there.

Not sure which renderer to pick? Start with Vulkan for the best FPS; if it won't launch on your system, the OpenGL build works everywhere. More on this in the FAQ.

5

Open the .mrpack file

Double-click the downloaded .mrpack file. AstralRinth picks it up automatically and installs Frost as a new instance — mods, configs, everything included, no manual setup.

If double-clicking opens something else (or nothing), open AstralRinth, hit the + button to add an instance, choose From file, and select the .mrpack there instead.

6

Launch and play

Once the install finishes, Frost shows up as an instance on the AstralRinth home screen. Select it, press Play, and you're in — with your offline account from step 3.

Own Minecraft? If you have a premium (Microsoft) account, use the official Modrinth App instead — the install steps are the same, see the FAQ installation guide.
Heads up: an offline account only works on servers that allow cracked players (offline-mode servers). Official servers that require a Microsoft account will still reject it — that's a Minecraft account thing, not a Frost thing.
